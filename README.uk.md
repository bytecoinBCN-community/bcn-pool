# bcn-pool

[English](README.md) · **Українська** · [Español](README.es.md) · [Português](README.pt.md) · [Türkçe](README.tr.md) · [Bahasa Indonesia](README.id.md) · [Tiếng Việt](README.vi.md) · [中文](README.zh.md)

Відкритий майнінг-пул Bytecoin (BCN) з **0% комісії** і виплатами **PPLNS**. Працює на <https://pool.bytecoin.community> (stratum `pool.bytecoin.community:3333`).

Це незалежний проєкт спільноти, не пов'язаний із засновниками Bytecoin чи bcndev.

## Як це працює

- **Логін:** ваша адреса BCN, за бажання `адреса.воркер`. Пароль може бути `d=NNNN` для фіксованої складності шар. Алгоритм `cn/0` (CryptoNight v0): працюють XMRig, BCN Miner і CryptoNight ASIC.
- **Кожна шара перераховується** CryptoNight із коду самого bytecoin. Хешу, який заявляє майнер, пул ніколи не довіряє. За сміттєві шари IP блокується на 10 хвилин.
- **Змінна складність (vardiff):** кожне з'єднання отримує складність шари, за якої шара приходить приблизно раз на 15 секунд.
- **PPLNS:** винагорода за блок ділиться за найновішою роботою обсягом 2 × складність мережі перед ним. Її зараховують, коли блок має 20 підтверджень; блок, що випав з основного ланцюга, не оплачується.
- **Виплати:** щогодини для балансів від 0,1 BCN, однією транзакцією на всіх. Пул нічого собі не лишає: комісію мережі за цю транзакцію беруть із виплат пропорційно. Адресу, на яку walletd не може надіслати кошти, пропускають і позначають, решта отримує виплати як завжди.
- **Захист від розколу:** блоки відправляються лише тоді, коли зовнішня нода (за замовчуванням node01/node02.bytecoin.org) має наш блок двома висотами нижче нашої вершини. Тож відрізаний від мережі пул не зможе будувати приватний ланцюг. Такий самий захист є в [bcn-stratum](https://github.com/bytecoinBCN-community/bcn-stratum). Майнінг також призупиняється, поки зовнішня нода на нашому ланцюгу випереджає нашу на два блоки або більше, щоб пул не майнив на застарілій вершині.

## Файли

| Файл | Що це |
| --- | --- |
| `pool.py` | Сам пул: stratum-сервер, перевірка шар, vardiff, відправлення блоків, дозрівання, PPLNS, виплати, статистика JSON |
| `bcnaddr.py` | Перевірка адреси без ноди: base58, префікс (`2…` legacy, `bcnZ…` Amethyst) і контрольна сума Keccak |
| `bcnlib.py` | Обгортка ctypes для `libbcnhelper.so` (шаблони блоків, CryptoNight), спільна з bcn-stratum |
| `test_pool.py` | Тести без ноди: PPLNS, розподіл комісії, vardiff, перевірка шар, логін |
| `bcn-pool.service` | Юніт systemd |
| `web/` | Сторінка пулу; читає `api/stats.json` і `api/miners/<адреса>.json` |
| `deploy/nginx-pool.conf` | Сайт nginx для сторінки і JSON |

`libbcnhelper.so` збирається з вихідного коду bytecoin у [bcn-stratum](https://github.com/bytecoinBCN-community/bcn-stratum) (`src/`); покладіть її поруч із `pool.py`.

## Запуск

Потрібні синхронізований `bytecoind` (RPC на `127.0.0.1:8081`) і `walletd` для гаманця пулу з авторизацією RPC:

```
walletd --wallet-file=pool.wallet --bytecoind-remote-address=127.0.0.1:8081 --walletd-bind-address=127.0.0.1:18071
```

Далі:

```
WALLETD_AUTH=user:password python3 -I pool.py --walletd http://127.0.0.1:18071/json_rpc
python3 test_pool.py
```

`python3 pool.py --help` показує налаштування: порти, складність, кількість підтверджень, вікно PPLNS, мінімальну виплату.

Гаманець пулу тримає ключ витрат, тож walletd має слухати лише localhost, файл гаманця має бути зашифрованим, а пароль RPC доступним тільки root. Тримайте баланс невеликим: усе понад баланси майнерів можна переводити на холодний гаманець.
